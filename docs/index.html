A language model, built up from the tokenizer.

kira.ai is PyTorch code for training a byte-level BPE tokenizer and a small decoder-only transformer on public text datasets, plus a few tools that run on your own laptop.

Read the source Run it

Where it stands: this is code, not a released model. The repository does not include trained weights, a tokenizer file or training data.

From text to a checkpoint

Data scripts stream or load public datasets from Hugging Face and write token files that the training loop memory-maps.

  1. prepare_data.py

    Streams English Wikipedia (Project Gutenberg books are optional), trains an 8,192-token byte-level BPE tokenizer and writes train.bin and val.bin.

  2. prepare_code_data.py

    Tokenizes Stack Overflow questions and an instruction-style Python code dataset with that tokenizer. Check each dataset's card for how its text was produced.

  3. ingest_cloned_repos.py

    Collects Python, Markdown and JSONL files from repositories you have cloned into one corpus and tokenizes it.

  4. prepare_sft_data.py

    Formats Dolly 15k and English OpenAssistant (OASST1) pairs as user and bot turns for fine-tuning.

  5. train.py

    Trains model.py with AdamW, warm-up and cosine decay, gradient accumulation and clipping, mixed precision on a GPU, and saves the checkpoint with the best validation loss.

  6. chat.py

    Loads a checkpoint and tokenizer for chat or raw completion with temperature and top-k sampling.

Local tools

Separate from the model: these are ordinary Python utilities. The web bridge matches keywords to actions and does not generate text with a model.

Laptop actions

Run shell commands, read, write and list files, open apps or links, and report CPU, memory, disk and battery use.

tools.py

Web bridge

A standard-library HTTP server with a small chat page, reachable from the laptop or a phone on the same network, on port 8080.

server.py

Document search

Splits text and code files into chunks and ranks them by shared keywords. It runs offline, is not a semantic or embedding search, and is not yet connected to chat. Its file types include .env, so choose folders with care.

personal_data.py

Interaction memory

Logs exchanges to local files, writes a summary note and can export prompt and response pairs. It does not update model weights.

evolution.py

Before you start the server

It listens on every network interface with no login, and a chat message beginning with run: is executed as a shell command. There is no sandbox. Anyone who can reach port 8080 can control the machine, so do not run it on a shared or untrusted network.

Run it

Python 3.10 or newer. Install the packages the code imports, then run the tests. The three tests cover the shell and file tools and memory start-up; they do not test the models.

git clone https://github.com/harctik/kira.ai.git
cd kira.ai
python -m venv .venv
# activate the environment, then:
pip install torch numpy tokenizers datasets tqdm psutil pytest
python -m pytest tests -v

# data, then training (a GPU is strongly advised)
python prepare_data.py
python train.py --model-size 15m

There is also a Colab notebook for training.
